# 集体协商授权与协议形成

记录劳资双方从代表授权、分轮提案到共同协议和履行的过程。

## 参与方与事实

主要参与方包括职工代表、企业代表、工会工作人员、调解人员。领域资料记录以下已经确认的事实：

- 集体协商围绕薪酬待遇和福利保障等现实议题展开
- 协商需要平衡企业经营实际与职工合理诉求
- 换位思考和寻找双方可接纳的平衡点是协商重点

## 业务约束

- 代表授权范围
- 保密成本材料
- 逐轮提案
- 双方确认
- 履行期限

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/bargaining_context.py` 负责读取和校验这些资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
