# 领域边界

记录劳资双方从代表授权、分轮提案到共同协议和履行的过程。

现有领域资料围绕以下边界组织：

- 代表与授权
- 提案版本链
- 保密资料权限
- 共同文本冻结
- 协议履行跟踪
- 承诺有效期与续办
- 回执与签名幂等归并
- 异文争议与监督追溯

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

协商服务（`src/negotiation_service.py`）遵循以下规则：

- 超出授权范围的条款只能暂存待确认，补充授权后才进入协商
- 每次让步必须引用本方上一版提案，条款标明可公开内容
- 调解人员只能推动共同文本，资料提供者不能单独认定自己数据成立
- 部分议题达成一致先冻结共同条款，未决内容继续协商
- 最终文本经双方各自确认才形成协议；双方签署完成才生效，生效前一方撤回即取消，绝不出现单方已生效
- 代表更换、授权收窄、利益冲突、会谈中止与重新开局只追加事件，不抹去此前过程
