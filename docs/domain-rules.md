# 领域边界

记录劳资双方从代表授权、分轮提案到共同协议和履行的过程。

现有领域资料围绕以下边界组织：

- 代表与授权
- 提案版本链
- 保密资料权限
- 共同文本冻结
- 协议履行跟踪

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

# 过程规则

`src/bargaining_service.py` 把上述边界落实为可执行的协商过程服务，规则如下：

## 代表、回避与授权

- 保存双方代表资格、回避关系和成员授权范围；调解人员、监督人员分别登记。
- 代表更换后原代表行为全部保留，新代表承接当前授权范围。
- 授权收窄时在途条款转入暂存待确认，历史授权版本不抹除。
- 登记回避关系（利益冲突）后，相关议题操作被拒绝，记录保留。

## 提案与暂存

- 企业与职工方分别维护本方立场，调解人员只能推动共同文本。
- 每次让步必须引用上一版提案，每条条款必须标明可公开内容。
- 超出当前授权范围的条款只暂存待确认，须本方代表在授权范围内确认或驳回。
- 提案可标注承诺有效期，逾期承诺仍需续延或提出新版本。

## 保密材料

- 保密成本材料不进入公开记录。
- 资料提供者不能单独认定自己数据成立，须他方佐证。

## 会议轮次

- 重复会议回执按键幂等归并。
- 会谈中止、恢复和重新开局只追加记录，不抹除此前过程。

## 冻结、生效与撤回

- 部分议题达成一致时先冻结共同条款，未决内容继续协商。
- 最终文本经双方各自确认同一摘要后才形成协议；异文进入争议。
- 签署与撤回并发时不能出现单方已生效：未生效前任何一方撤回即阻止生效。
- 异步签名按方幂等归并；撤回已生效协议转为争议记录。

## 重启与追溯

- 期限届满或服务重启后，待确认承诺、调解事项和履行节点继续处理。
- 参与方可看到适合自身的下一步；监督人员能从协议条款追到授权、提案变化、法律依据和履行结果。
